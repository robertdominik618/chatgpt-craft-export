# Privacy Policy

Craft Export for ChatGPT is designed to work locally in the browser.

## Data collection

The extension does **not** collect, sell, transmit, or store analytics about the user or their conversations.

## Conversation content

When the user presses an export action, the extension reads the rendered content of that specific ChatGPT response only for the purpose of creating the requested local document.

- DOCX generation happens locally in JavaScript.
- PDF generation uses a local print view and the browser's print engine.
- No conversation content is sent by this extension to an external server.

## Network requests

The extension does not intentionally make network requests of its own.

## Permissions

The extension requests page access only for ChatGPT web domains so it can insert the export controls.

## Third parties

ChatGPT, OpenAI, WordCraft, PdfCraft, ArtCraft, Microsoft, Adobe, browser vendors, and the operating system have their own privacy practices. This project is independent of those services.
